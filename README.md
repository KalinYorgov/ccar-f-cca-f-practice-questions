## Exam facts (exam guide v1.0, July 2026)

| Fact | Value |
|---|---|
| Exam code | CCAR-F (earlier materials say CCA-F; same exam) |
| Items / time | 60 items, 120 minutes |
| Format | multiple-choice and multiple-response; each item states how many to select |
| Domains | Agentic Architecture & Orchestration 27% · Tool Design & MCP 18% · Claude Code Configuration 20% · Prompt Engineering & Structured Output 20% · Context Management & Reliability 15% |
| Passing | scaled score 720 on 100–1,000 (not a percentage) |
| Fee | $125 USD; Pearson VUE, online or test centre |
| Eligibility | Claude Partner Network organisations only; company email required |
| Official practice exam | retired 30 June 2026; the guide's 12 sample questions remain |
